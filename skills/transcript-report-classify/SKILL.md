# 分类与证据报告

先确认完整正文、来源时间与质量标记。信息不足时出复核说明，不能凭模板补全内容。没有原音时不能宣称已核实转写错误。[分类与审阅](references/reporting.md)

分类与报告遵循用户的标签表与用途。标签表缺失时采用可解释的临时标签并标明待确认；公开示例只使用合成标签，不携带原项目的真实主题。

根据语义边界划分会话。一个来源可有多主题，一个连续会话也可跨分卷；保留来源、偏移和每段分类证据。处理状态、信息类型、主题与质量标签分别登记。

日常分类可从普通模型 medium 起步，完整证据报告可从 high 起步，困难的跨来源冲突或仲裁可用更强模型复查。这是可调整策略，明确记录实际 model／effort；skill 本身不保证自动切换会话模型。不得因推理强度更高而虚构更可靠的识别内容。

输出摘要、材料陈述、已明确决定、行动与缺失字段、未解事项、分析建议、证据索引和质量限制。把意见、愿望、建议与已确认事实区别开。模型升级应针对具体缺陷，不无限重复审阅。

全文覆盖、证据可追溯、无虚构负责人或期限、分类未知项及交付完整性通过后，才能报告完成。若生成 PDF，逐页渲染检查；公开分享另建白名单目录，不复制原始案例。
