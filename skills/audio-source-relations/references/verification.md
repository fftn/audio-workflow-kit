# 关系核验

- 原件 SHA-256 相同证明文件字节相同；容器元数据差异会使同一编码流的文件哈希不同。
- 无重编码提取同编码音频流再做哈希，记录提取方式；不要把重新编码后哈希相同作为原始流一致证明。
- 同源不同格式用完整解码时长及多处独立声学锚点验证，避免只抽开头。
- 长文件对应多个分卷时逐卷核验，并记录累计偏移；未核对的连接处保留不确定性。
- 跨设备先用独立文字锚点筛选，再用声学锚点确认偏移；检查锚点跨度、一致性、重复背景与时钟漂移。
- 短 ASR 片段应跨段检索，避免只匹配长句而漏掉碎片化输出。空文字不能据此排除重叠。
- 两个来源复用同一融合稿，不构成独立的文字或声学重叠证明。
- 用 ffprobe 声明时长还不够：解码错误、CRC 错误、丢包与实际可解码时长应单独记录。

实际关系图可以包含历史关联、文本候选和声学确认层，显示证据范围；只有覆盖充分的关系才能用于去重时长估算。
