# 来源关系与复用

冻结用户指定的来源集合，建立原件哈希及音频规格清单。文件名、日期相近或探测时长相等都不能独立证明重复。[关系核验](references/verification.md)

区分文件字节副本、无重编码提取后的编码流副本、声学同源副本、连续分卷对应、部分重叠与候选关系。记录所用证据和置信状态，不把这些关系相加为独立会议数。

复用前确认结果对应准确来源及模型版本。已有综合报告只表示覆盖关联，不代表每份音频都有独立逐场报告。部分重叠保留两路独有时段，来源损坏时记录可解码范围和替代来源。

输出逐文件状态、关系索引、结果复用指向和未解决项。执行分析使用副本，原件保持原位；只有用户另行要求删除或移动时才处理原件。
