# 公开内容范围

本分享包通过重新编写和文件白名单构建，不对原项目整体压缩，也不把真实记录替换几个名字后继续分发。

## 保留内容

模型名称、公共模型链接、算法配置、硬件规格、匿名化计时、计算估算、流程选择、交付结构、质量控制、话题无关分类、通用可执行 helper 与完全合成的测试样例。

## 排除内容

真实音频、录音全文、摘要或报告；人名、单位、联系方式、实际议题和案例细节；真实主题标签表；原始来源名称、录制日期、目录结构、内容哈希；私人账号、主机别名、IP、SSH 配置、绝对家目录和历史运行路径；带真实文本的日志、截图、PDF、提示词词表和项目专用词汇修正表。

匿名性能表只从日志抽取白名单数值与公开模型身份。内容长度、源哈希和样本定位线索未附入；计时统计本身仍是内部经验，不能公开复现其原样本。

## 技术泛化

- 接收方在自己的配置中填写计算设备、缓存目录和远端连接；默认不传输到任何主机。
- 公开 skill 没有固定个人术语表，也没有自动纠正真实专名的规则。
- 分类表留空，由接收方配置；示例文字来自人为构造的“主题A／主题B”材料。
- 可以本地或自托管处理。若接收方选择云文本模型，转写仍会进入该提供方的处理边界；音频未上传云端不等于全文完全离线。
- 下载权重、安装依赖与模型缓存是环境准备，本包没有替接收方执行这些动作。

## 持续维护

新增可分享文件应先逐份审阅，然后更新 `PUBLIC_FILES.json` 的显式白名单，再运行 `tools/audit_public_bundle.py`。不要把它改成递归放行。

扫描会检测路径、邮箱、IP、私钥、常见 token、历史数据线索及异常引用；机械扫描不能证明不存在语义泄露，实际发布前仍应只在本分享目录内核对内容。

本包已经完成逐文件人工式内容审阅、引用检查、skill 格式检查、合成数据检查、dry-run 和 ZIP 成员核对。Git 仓库仅包含此分享目录的白名单文件；根目录的 Git 管理目录不参与内容扫描或 ZIP 打包，其他新增文件仍必须通过白名单审阅。忽略规则用于减少误提交风险，不能替代发布前审阅。
