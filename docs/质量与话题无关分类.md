# 质量与话题无关分类

## 三个独立维度

不要把“已运行”“有报告”和“内容可靠”合成同一个完成标签。建议分别登记处理状态、内容类型与质量风险。

| 维度 | 可复用标签示例 |
|---|---|
| 处理状态 | 未识别、已识别待审阅、已出报告、低信息复核、同源复用、部分重叠、损坏 |
| 信息类型 | 任务沟通、一般交流、节目／播放、测试片段、无稳定文字、混合材料 |
| 质量风险 | 时间定位待核、声音身份待核、输出截断、疑似幻觉、数字／专名待核、长静音稀疏文字 |

这些属于话题无关的信息类型和质量标签。具体主题标签由接收方提供分类表；公开版本只使用“主题A”“主题B”等合成占位，不附实际业务分类。

## 分段与多主题

- 先阅读完整文字，再按语义转换与活动边界划分会话；固定时长切块只是计算单位。
- 一个文件可以包含多个会话，一个会话也可能跨连续分卷。
- 每段可以有主主题和多个辅助主题；无法稳定判断时保持“待分类”。
- 记录标签证据范围、人工复核状态与标签体系版本。
- 文件数、会话数、主题数和去重时长分别统计，不能混加。
- 字数、术语密度与行动词只是筛选信号；不能独立证明内容有价值或需要行动。

## 时间与声音质量

检查时间是否有限、非负、end 大于 start、是否越界。不要凭短句跨越很长时间段来推断持续发言，也不要通过格式化时间掩盖零时长或倒退。

空识别不等于没有讲话。声音活动明显但文字稀疏时，做解码／声学检查或局部补识别，并保留“不足以恢复内容”的结论。

分离结果最多 4 个身份是模型能力约束；多人会议可能合并。没有可靠相邻证据时保留“说话人未知”。分段内两种声音的时长重叠只是可能多人同时发言的证据，不代表已经恢复两人的各自文字。

## 报告证据

报告可包含摘要、可定位陈述、已明确的决定、行动项、未解问题、风险与分析建议。行动项的负责人、期限和依据缺失时明确缺失；不能从愿望或讨论自动生成承诺。

报告模型应看到完整正文或覆盖全文的证据分块，并保留各块的出处。不能只取开头几段，不能把模板里的字段填满当成完成。

## 可测效果

| 环节 | 适合的评价 | 当前公开证据边界 |
|---|---|---|
| 文字识别 | 人工参考文字上的 CER／WER，数字与专名单项准确率 | 没有公开人工标准答案，暂不排名 |
| 说话人分离 | 人工说话人轨迹上的 DER／JER，转场与多人重叠复核 | 没有统一标准轨迹，不宣称匿名标签准确率 |
| 时间定位 | 对齐误差、越界率、异常跨度率 | 可以做结构检查；结构正常不代表语音位置正确 |
| 分类 | 人工标签集上的一致率、宏平均 F1、待分类率 | 主题表与标注集未公开，只保留方法 |
| 报告 | 全文覆盖、断言可追溯率、漏项、虚构承诺、复核改动率 | 能列验收清单，尚无受控模型优劣实验 |
| 交付 | 原件哈希、远端清理、文件完整性、PDF 逐页视觉验收 | 属于操作可靠性，不替代语义准确率 |

与已有自动转写做相似度比较，只能说明与该转写的一致程度；即使分数很高，也不能据此称为识别准确率。
